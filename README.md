## DetectX

Advanced Hardware Detection & Game Compatibility Analyzer
## DetectX is an Electron app or a software developed using Basic big 3 web development languages such as HTML,CSS & JS
The Major purpose of this software is to serve the users as a standalone all-in-one platform that facilitates in quick hardware detection of users CPU,GPU and RAM details and compare them across 100+ Games stored in our database and recommend the users the best games they can play smoothly in their iGPU and dGPU
I have used simple but professional UI designs that will make it easier for anyone to use it without difficulties
Being built using web development languages , this software is more lightweight and faster.
Compared to other already available softwares such as CPU-Z , GPU-Z and can you run it? The DetectX provides more accurate and all-in-one solution in detection and also live game compatibility as well PC SCORE rating

### Features
- ▶️Complete CPU detection (model, codename, year, cores, threads)
- ▶️Separate iGPU and dGPU detection with vendor logos
- ▶️100+ games compatibility checker
- ▶️Performance scoring system
- ▶️Export reports (JSON & TXT)
- ▶️Open Windows System Information
- ▶️Modern professional UI

### System Requirements
- Windows 7 or later
- 64-bit or 32-bit
- 4GB RAM minimum
- 250MB disk space

### Installation
1. Download `DetectX-Setup-1.0.0.exe`
2. Run the installer
3. Follow installation wizard
4. Launch from desktop shortcut
